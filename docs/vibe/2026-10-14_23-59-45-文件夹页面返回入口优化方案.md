# 文件夹页面返回入口优化方案

## 最终结论

根据用户确认，方案收敛为：只把现有返回按钮和页面标题从滚动内容移到固定的 `GlassAppBar`，不增加文件夹左边缘滑动返回，不进行文件夹路由重构，也不扩展系统返回逻辑。

这个最小方案已经能解决当前问题：文件很多、列表滚动到任意位置时，顶部返回按钮始终可见，用户可以直接返回上一级或课程库根目录。

## 当前情况

- `v3/lib/library_page.dart` 的固定 `GlassAppBar` 显示“雷 player”、设置和更多操作。
- 文件夹、最近播放和收藏的返回按钮及标题位于 `libraryHeader()`。
- `libraryHeader()` 是 `CustomScrollView` 中的首个 `SliverToBoxAdapter`，会随列表滚出屏幕。
- 现有按钮逻辑已经能够处理标签页返回和父文件夹计算，问题只在入口位置不固定。

## 修改后的交互

### 课程库根目录

- 顶部标题显示“雷 player”；
- 不显示返回按钮；
- 右侧操作保持不变。

### 文件夹页面

- 顶部左侧固定显示返回按钮；
- 顶部标题显示当前文件夹名称；
- 点击返回按钮时，多级目录返回父目录，一级目录返回课程库根目录；
- 列表无论滚动到哪里，按钮都不离开屏幕。

### 最近播放和收藏

- 将原来随列表滚动的返回按钮和标题一并移入固定导航栏；
- 点击返回回到课程库，并保持现有 `folder` 状态语义。

### 设置页

- 本次不调整设置页现有返回按钮和已有手势逻辑，避免扩大修改范围。

## 明确不做

- 不为文件夹页面增加左边缘或其他滑动返回；
- 不增加新的手势状态字段；
- 不增加手势阈值、动画或触觉反馈；
- 不把每级文件夹改造成独立 Navigator 路由；
- 不改变 Android/iOS 系统返回行为；
- 不改变导入、播放、文件菜单、排序和布局逻辑。

## 建议的代码调整范围

1. `GlassAppBar.leading`：仅在 `tab == 1`、`tab == 2` 或 `(tab == 0 && folder.isNotEmpty)` 时显示现有返回按钮；不能单独用 `folder.isNotEmpty` 判断，否则从子文件夹进入设置页时会与设置页原有返回按钮重复。
2. `GlassAppBar.title`：按当前状态显示“最近播放”“我的收藏”、当前文件夹名或“雷 player”。
3. 返回按钮继续使用现有逻辑：`tab != 0` 时回课程库，否则将 `folder` 改为父路径。
4. 从 `libraryHeader()` 移除原来的返回按钮和标题行。
5. `libraryHeader()` 继续保留“继续学习”卡片及原有间距逻辑。
6. 文件夹标题显式使用单行省略，保证不遮挡右侧设置和更多按钮。

## 修改前后对比

| 项目 | 修改前 | 修改后 |
| --- | --- | --- |
| 返回按钮 | 位于滚动内容，会滚出屏幕 | 位于固定顶部栏，始终可见 |
| 当前页面标题 | 位于滚动内容 | 位于固定顶部栏 |
| 返回逻辑 | 已能返回标签页或父目录 | 保持不变 |
| 文件夹滑动返回 | 不支持 | 仍不支持，属于明确取舍 |
| 路由结构 | 单页面 `folder` 状态 | 保持不变 |
| 列表和播放状态 | 现有行为 | 保持不变 |

## 修改原因

问题的直接原因是返回按钮放错了层级：导航控件被放进了会滚动的内容。把它移到固定导航栏即可解决，无需引入新的手势识别或路由架构。

## 可能影响与注意事项

- 文件夹名称较长时顶部空间有限，必须单行省略；`GlassAppBar` 已提供标题宽度约束，但标题仍建议显式设置 `maxLines: 1` 和 `TextOverflow.ellipsis`。
- 顶部左侧增加按钮后，标题可用宽度会缩小，但不会覆盖右侧按钮。
- 应保留 `PageStorageKey('library/$tab/$folder')`，避免影响父目录滚动位置恢复。
- 本次不新增系统返回和手势入口，因此不会产生手势与纵向滚动冲突，也没有额外手势状态卡住的风险。
- 设置页有自己独立的返回区域，本次不迁移，避免同时改变多个页面。

## 手工验收建议

根据项目规则，本次不执行自动构建或测试。后续实现后建议人工验证：

1. 进入一级文件夹并滚动到底部，顶部返回按钮仍可见，点击后回到根目录。
2. 进入两级以上目录，连续点击返回时每次只返回一级。
3. 父目录滚动到中部后进入子目录，再返回时父目录恢复原位置。
4. 最近播放和收藏列表滚动后，顶部返回按钮仍可用。
5. 根目录不显示无意义的返回按钮。
6. 长文件夹名、窄屏和大字体下，标题省略且不遮挡设置、更多按钮。
7. 当前播放卡片、导入状态、列表/网格切换、排序和文件菜单保持原行为。

- 影响：文档方案更简单；不改变现有文件夹返回语义，仅改变入口位置。
