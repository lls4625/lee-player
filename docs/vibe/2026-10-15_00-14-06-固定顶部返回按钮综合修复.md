# 固定顶部返回按钮综合修复

## 修复结果

已按照最终优化方案完成代码修改：文件夹、最近播放和收藏页面的返回按钮及标题已从可滚动内容迁移到固定的 `GlassAppBar`。文件列表滚动到任意位置时，返回按钮都保持可见。

本次严格采用最小方案，没有增加文件夹侧滑返回、系统返回拦截、文件夹路由、导航锁、等待动画或原生端逻辑。

## 修改前的情况

- 返回按钮和当前页面标题位于 `libraryHeader()`。
- `libraryHeader()` 是 `CustomScrollView` 中的首个 `SliverToBoxAdapter`。
- 长列表向下滚动后，返回按钮会离开屏幕。
- 文件夹通过修改 `folder` 状态进入和退出，现有返回计算本身可以正常工作。
- 设置页有独立的“返回课程库”按钮和既有滑动处理。

## 修改后的情况

- `tab == 0 && folder.isNotEmpty`：顶部显示固定返回按钮，标题显示当前文件夹名。
- `tab == 1`：顶部显示固定返回按钮，标题显示“最近播放”。
- `tab == 2`：顶部显示固定返回按钮，标题显示“我的收藏”。
- `tab == 0 && folder.isEmpty`：不显示返回按钮，标题显示“雷 player”。
- `tab == 3`：不新增顶部返回按钮，继续使用设置页原有返回入口。
- 原滚动页头只保留“继续学习”卡片和原有间距，不再包含导航控件。

## 具体修改内容

修改文件：`v3/lib/library_page.dart`

### 1. 精确控制固定返回按钮

新增 `showsLibraryContextBack`，条件为：

```dart
tab == 1 || tab == 2 || (tab == 0 && folder.isNotEmpty)
```

该条件明确排除设置页。即使用户从子文件夹进入设置，`folder` 仍非空，也不会在设置页产生第二个返回按钮。

### 2. 复用并集中现有返回逻辑

新增 `returnFromLibraryContext()`：

- 最近播放或收藏返回时，只把 `tab` 改回课程库；
- 文件夹返回时，只把 `folder` 改为父路径；
- 非适用状态直接返回，不执行无意义状态修改。

该方法为同步 UI 状态切换，不依赖导入、扫描、播放或原生通道。

### 3. 根据状态生成固定标题

新增 `libraryAppBarTitle()`，标题优先按 `tab` 判断，再处理 `folder`：

- 最近播放、收藏和品牌标题继续使用 `LText`；
- 用户文件夹名使用普通 `Text`，不作为本地化键；
- 所有标题均限制一行并使用省略号，避免遮挡右侧按钮。

### 4. 移除滚动区导航行

从 `libraryHeader()` 删除原来的返回按钮和标题行，只保留继续学习区域。这消除了返回入口随列表滚动离开屏幕的根因。

## 修改原因

返回按钮属于页面导航控件，不应放在会滚动离开视口的内容区域。将现有控件迁移到固定顶部栏即可解决问题，不需要引入新的交互模型。

## 用户操作闭环

文件夹操作链路现在为：

`根目录 → 打开文件夹 → 滚动到任意位置 → 点击固定返回 → 父目录/根目录`

- 一级文件夹返回根目录；
- 多级文件夹每次点击返回一级；
- 最近播放和收藏返回课程库；
- 根目录没有内部返回目标，因此不显示按钮；
- 设置页保留原有返回入口，不出现重复按钮。

## 可能影响与注意事项

- 文件夹名很长时会在顶部单行省略，这是为了保证设置和更多按钮始终可用。
- 返回仍会触发当前已有的列表过滤和排序；超大目录可能存在的短帧停顿属于既有行为，并非本次修改新增。
- `PageStorageKey('library/$tab/$folder')` 未修改，父目录滚动位置恢复机制保持不变。
- 返回按钮未绑定 `fileBusy`、`scanning` 或 `importing`，文件操作期间不会因为忙碌状态而无法离开目录。
- 当前播放、继续学习、导入状态、文件菜单、布局和排序逻辑均未改变。
- 文件夹页面仍不支持侧滑返回，这是用户确认后的明确取舍。

## 验收建议

根据项目规则，本次没有执行构建、编译或自动测试。建议用户手工验证：

1. 一级文件夹滚动到底部，固定返回按钮仍可见并能返回根目录；
2. 进入三级目录，连续点击时每次只返回一级；
3. 从子文件夹进入设置，设置页只有原有“返回课程库”入口；
4. 从子文件夹进入最近播放或收藏，顶部标题正确，返回后回到原子文件夹；
5. 长文件夹名、大字体和窄屏下，标题省略且不遮挡右侧按钮；
6. 导入、扫描或播放过程中仍能立即返回；
7. 从子文件夹返回后，父目录恢复原来的滚动位置；
8. 根目录不显示返回按钮。

## 文件变更记录

- 修改前：导航按钮和页面标题位于滚动内容，会随长列表滚出屏幕。
- 修改后：导航按钮和标题位于固定顶部栏，设置页被精确排除。
- 修改内容：修改 `v3/lib/library_page.dart`，新增三个小型 UI 状态方法并删除滚动区导航行；新增本记录文档。
- 修改原因：解决长列表中无法直接返回的问题，并落实评估中发现的设置页重复入口风险。
