# 隐私政策在线入口变更记录

## 修改目标

保留 App 内随包分发的本地隐私政策，同时增加在线隐私政策入口：

<https://www.wlsp1881.com/leeplayer/privacy-policy.html>

## 修改前情况

- “设置 → 关于雷player → 隐私政策”只能查看随 App 打包的本地文本。
- App Store Connect 可以单独填写线上隐私政策 URL，但 App 内没有跳转到该公开网页的入口。
- 项目没有用于打开普通外部 HTTPS 地址的 Flutter 原生通道。

## 修改后情况

- 本地隐私政策继续保留，用户离线时仍可查看与当前 App 版本相匹配的政策内容。
- 只有隐私政策页面底部新增“查看在线隐私政策”按钮；版权与开源许可页面不显示该按钮。
- 点击按钮后由 iOS 使用系统浏览器打开已确认的 HTTPS 地址。
- 原生端只接受格式有效、具有主机名的 HTTPS 地址。
- 系统无法打开网页或原生通道不可用时，App 显示本地化失败提示，本地政策不受影响。
- 按钮及失败提示已提供简体中文、繁体中文、日文和英文文案。

## 修改内容

| 文件 | 修改 |
| --- | --- |
| `v3/lib/library_page.dart` | 为法律文档页面增加可选在线地址和按钮；隐私政策入口传入线上 URL；增加失败反馈 |
| `v3/lib/app_localizations.dart` | 增加在线隐私政策按钮及失败提示的四语言文案 |
| `v3/ios/Runner/AppDelegate.swift` | 注册 `lei.player/app` 原生通道并通过系统浏览器打开经过校验的 HTTPS URL |

## 修改原因

- Apple 要求隐私政策既出现在 App Store Connect 元数据中，也应在 App 内易于访问。
- 本地和在线双入口兼顾审核要求、离线可用性及后续政策更新维护。
- 使用现有 Flutter/iOS 原生通信模式，避免为了单个固定链接增加新的第三方依赖。

## 影响与注意事项

- 在线地址硬编码在当前 App 版本中。如果未来修改 URL，需要修改代码并发布新版本，同时更新 App Store Connect。
- 如果只更新相同 URL 下的 HTML 内容，不需要发布新版 App。
- 应长期维持当前 URL 可访问；迁移域名时建议保留旧地址并设置重定向。
- 本次按项目要求未执行构建、编译或自动化测试，需要由开发者手动确认按钮样式、系统浏览器跳转和失败提示。
